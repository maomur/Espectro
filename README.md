# Espectro

Test de ideología política jugable para el móvil: 25 preguntas en 5 fases (duelo a ciegas, ¿sí o no?, votación en el Congreso, termómetro y reacciones) que te sitúan en la escala izquierda–derecha, de la extrema izquierda a la extrema derecha, con tu posición en economía y en valores.

Basado en la escala de autoubicación ideológica del CIS y en las dimensiones económica y social (GAL-TAN) del Chapel Hill Expert Survey.

## Desarrollo

```bash
npm install
npm run dev      # servidor local
npm test         # tests del motor
npm run build    # compilación para producción (dist/)
```

Stack: React 19 + Vite + TypeScript, Tailwind v4, Zustand, Vitest.
